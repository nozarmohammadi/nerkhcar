# مینی‌اپ نرخ‌کار: بستهٔ طراحی (webapp_v2)

محل: /opt/nerkhcar/webapp_v2/ (فعلاً سرو نمی‌شود؛ webapp فعلی دست‌نخورده است).
راهنمای کلاس‌ها، رنگ‌ها و آیکون‌ها: webapp_v2/README.md.

## قانون نگهبانی (برای هر AI و هر انسان)
1. رنگ، فاصله، فونت: فقط css/tokens.css. متن فارسی: فقط js/texts.js. آیکون: فقط js/icons.js. ظاهر کلاس‌ها: فقط css/components.css.
2. هر فایل حداکثر ۲۰۰ خط؛ بدون innerHTML؛ بدون کتابخانه (جز اسکریپت رسمی تلگرام).
3. پچ روی پچ ممنوع: فایلی که ۳ بار پچ شد بازنویسی می‌شود.
4. کلاس تازه: اول در components.css تعریف و در README ثبت شود، بعد در js استفاده شود.
5. نگهبان خودکار: venv/bin/python -m pytest tests/test_webapp_rules.py (جزو چک سبز پیش از commit). این تست نباید ضعیف یا حذف شود.
6. نصب روی سایت زنده (جایگزینی webapp) یک قدم جدا در چک‌لیست است: با بکاپ، تست و تأیید مالک. بعد از نصب، مسیر داخل تست به webapp تغییر کند.
