# قوانین کد نرخ‌کار

1. هر فایل حداکثر ۲۰۰ خط، هر تابع حداکثر ۳۰ خط.
2. هر دکمه = یک فایل handler؛ handler فقط ورودی/خروجی، منطق در core.
3. core هرگز تلگرام را import نکند.
4. همهٔ متن‌های فارسی فقط در texts/.
5. پچ روی پچ ممنوع؛ فایلی که ۳ بار پچ شد بازنویسی می‌شود.
6. بعد از هر تغییر، کد مرده و importهای بی‌استفاده حذف شود.
7. callback_data کوتاه با شناسهٔ عددی (حداکثر ۶۴ بایت).
8. لاگ بدون اطلاعات شخصی؛ فقط شناسهٔ عددی تلگرام.
9. تغییر دیتابیس فقط با migration و بکاپ قبلش.
10. هر خطای پیش‌بینی‌نشده با error handler سراسری ثبت شود.

چک خودکار: `venv/bin/python tools/check_rules.py`
